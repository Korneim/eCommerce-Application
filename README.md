## 📖 Description

B&G Bookish is an online bookstore powered by CommerceTools.

🛍️ Users can:

* browse through three main categories — Books, Manga, and Comics,

* view detailed descriptions for each product 📝,

* add selected items to the basket 🧺,

* and proceed to checkout 💳.

🔐 Additional features include:

* user registration and login 👤,

* product search 🔍,

* categorization and sorting 🗂️
— all designed to make the shopping experience smooth and enjoyable 🎯.

The application was created as part of [JavaScript/Front-end 2024Q4](https://rs.school/courses/javascript-ru) ([eCommerce Application](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/eCommerce-Application)) by [@Korneim](https://github.com/Korneim) and [@redinar](https://github.com/redinar)

## 🚀 Getting Started

1. Clone the repository on your computer
```bash

git clone https://github.com/Korneim/eCommerce-Application.git

```
2. Navigate to the project directory
```bash
cd eCommerce-app
```
3. Switch to the ```develop``` branch and pull the latest changes
```bash
git switch develop
git pull
```
4. Install all dependencies
```bash
npm install
```
5. Run the application in development mode
```bash
npm run dev
```
6. Build the production version
```bash
npm run build
```

## 💻 Available Scripts
* ```npm run dev``` - run the application in development mode using Vite and hot module replacement
* ```npm run build``` - build the production version of the application using Vite and TypeScript
* ```npm run preview``` - preview the production build locally on a dev server
* ```npm run lint``` - run ESLint to check for code style issues and errors
* ```npm run format``` - format code automatically using Prettier
* ```npm run stylelint``` - lint styles using Stylelint (for CSS/SCSS files)
* ```npm run stylelint:fix``` - automatically fix stylelint errors
* ```npm run test``` - run unit tests using Jest
* ```npm run commitlint``` - validate commit messages against conventional commit rules
* ```npm run prepare``` - set up Husky Git hooks (automatically called by npm on install)
